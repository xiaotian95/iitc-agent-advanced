# IITC 智能体开发工程师（高级）备考作战台

一个**离线可用**的备考网页，面向「IITC 工信人才岗位能力评价 · 智能体开发工程师（高级）」。

双击 `index.html` 即可打开（推荐 Chrome / Edge）。也可以按下面的方式在本机起一个网页服务，用浏览器或手机访问。所有数据保存在本机浏览器，不上传任何服务器。

## 在浏览器 / 手机上访问

- **本机地址**：<http://127.0.0.1:8080/index.html>
- **手机（同一 Wi-Fi）**：<http://192.168.0.6:8080/index.html>

启动方式：

1. 双击 `启动本地网页.bat`（会打开浏览器并启动服务，窗口不要关）。
2. 手机访问前，先双击 `开放手机访问端口.bat` 并允许管理员权限，放行 8080 端口。
3. 电脑重启后服务会停止，重新双击 `启动本地网页.bat` 即可。

> 页面是纯静态文件，直接双击 `index.html` 也能用；起服务只是为了手机/局域网访问。

## 包含什么

| 模块 | 内容 |
|---|---|
| 学习概览 | 三科分值结构、高频分值分布、四步备考路线、考试日期倒计时 |
| 考点精讲 | 12 章，含正文、必背考点、易错点、考法提示、章节目录、进度记录 |
| 章节刷题 | 120 道客观题（单选 50 / 多选 40 / 判断 30），选项随机、即时解析、错题本 |
| 模拟考试 | 按科目一 20 分结构组卷：40 题、60 分钟、自动评分、逐题解析 |
| 主观题 | 10 道科目二高频问答，含答题框架与参考答案 |
| 工程实践 | 报告六段结构、评分维度对照、10 个选题、提交清单、答辩 18 问 |
| 冲刺计划 | 14 天日程，可勾选打卡，进度自动保存 |
| 速记卡 | 35 张考前速记 |

## 怎么用（建议顺序）

1. **首页设置考试日期**，倒计时和每日任务会跟着更新。
2. 按重要度读「考点精讲」，读完一章点「标记本章已读」，顺手做本章练习。
3. 刷题错题自动进错题本，考前只刷错题 + 速记卡。
4. 主观题不要背全文，背**答题框架**（结论先行 → 分层展开 → 量化收尾），再用参考答案对照补细节。
5. 工程实践占 50 分：先按六段结构起稿，再按评分表自检，最后计时演练答辩。

## 内容与事实说明

- 考试科目结构（高级：专业知识 20 分 / 技术技能 30 分 / 工程实践 50 分）整理自公开的 IITC 岗位能力评价说明，**具体题型、分值、提交方式请以你当期收到的官方通知为准**。
- 官方学习平台：<https://rencai.gxbxxpt.org.cn/>
- 法规与技术事实（MCP、生成式 AI 管理办法、内容标识办法等）按公开资料整理；涉及具体条款请以官方原文为准。
- 题库为原创练习，不对应任何官方真题。

## 想自己改内容

- `data/kb-core.js`、`data/kb-tech.js`、`data/kb-ops.js`：知识章节（`window.KB_CORE / KB_TECH / KB_OPS`）。
- `data/questions.js`：题库（`window.QUESTIONS`），字段：`id / type / chapter / level / stem / options / answer / explain / tag`。
- `data/exam.js`：考试信息、14 天计划、速记卡。
- `data/subjective.js`：主观题、报告指南、答辩题。
- `assets/style.css`：配色与版式；`js/app.js`：路由、刷题与模拟考逻辑。

改完刷新页面即可。清空浏览器站点数据会同时清掉学习进度。

## 打印
